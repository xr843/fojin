Buddhist canon · infrastructure an AI can call

让 AI 引用佛典时，
每一句都能被核对

汉传、巴利、梵、藏四系典籍，一套只读接口。检索、读原文、跨藏对照， 以及大模型最容易出错的那一步 —— 逐字核验引文是否真的存在、是否真在你标的出处。 每一段经文都带一个可解析的 URN 引证。

Search, read and cross-reference the Buddhist canon over one read-only API, and verify every quotation verbatim before you serve it. Every passage carries a resolvable citation URN.

接入 Claude Code（其它 MCP 客户端指向同一个 URL 即可）

claude mcp add --transport http fojin https://mcp.fojin.ai/mcp

Tools七个工具

托管在 mcp.fojin.ai，匿名可用、按客户端限流、全部只读。 同一套工具也可以用 uvx fojin-mcp 在本地以 stdio 方式运行。

工具返回什么
verify_quote 逐字核验引文：这句话在藏经里存不存在、在哪几处； 并且分开回答「引文是否为真」与「出处是否属实」。找不到时给出最接近的原文与相似度。
search_corpus 语义检索全语料（1 万余部典籍、30 余种语言），每条命中带 URN、标题、片段与相似度。
read_passage 某经某卷的完整原文 —— 要引用就引用这里返回的文字，不要凭记忆。
get_parallels 跨藏对齐的平行段落（汉 ↔ 巴 ↔ 梵 ↔ 藏），各自带 URN 与深链。
lookup_dictionary 32 部佛学辞典的词条检索。
lookup_entity 知识图谱实体：人物、地点、著作、义理名相。
resolve_urn 把 fojin: URN 解析成阅读链接并确认它确实存在。

Verify before you quote引文核验

大模型写佛教内容时最典型的错误不是编造经名，而是把复述当成逐字引用， 或者把一句真经文安到错误的出处上。这两件事需要分开回答 —— 所以核验结果里 verbatim 与 cite_matched 是两个字段。

请求 — 一句真经文，配一个常见但错误的出处

GET https://fojin.app/api/verify/quote
      ?q=諸行無常，是生滅法，生滅滅已，寂滅為樂
      &cite=T0374

响应（节选）

{
  "verbatim": true,
  "bucket": "exact",
  "cite_resolved": true,
  "cite_matched": false,
  "matches": [
    { "urn": "fojin:cbeta/T2919.1", "title_zh": "佛母經" },
    { "urn": "fojin:cbeta/T1528.1", "title_zh": "涅槃經本有今無偈論" },
    { "urn": "fojin:cbeta/X1277.7", "title_zh": "高峰龍泉院因師集賢語錄" }
  ]
}

引文为真，出处不实。 雪山偈四句连写并不出现在《大般涅槃经》(T0374) 里 —— 经中是罗刹先说半偈、 再说后半的叙事结构。四句合诵见于《佛母经》等三十余处引用文献。 这种「话是真的，但不在你说的那一卷」正是 cite_matched 存在的理由： 沿用旧管线「同名任意卷也算数」的回退，就会把它误判为通过。

对照 — 一句听起来很像佛经的伪造引文

{
  "verbatim": false,
  "bucket": "absent",
  "similarity": 0.818,
  "closest": { "urn": "fojin:cbeta/X1591.4" }
}

没有逐字命中，但给出了最接近的真实段落 —— 模型可以据此把杜撰的句子换成真出处， 而不是简单地丢弃。caveats 字段会如实声明当前的覆盖边界 （只覆盖汉文语料、尚未折叠 CBETA 缺字异体），请把它一并转述，不要过度声称。

The URN contract可解析的引证

每一段经文都带一个可移植的标识，形如 fojin:cbeta/T0251.1 （典藏 / 编号 . 卷）。它可以被直接引用、可以回到 resolve_urn 验证， 也可以解析成人能点开的阅读链接。跨藏经统一编号，与 CBETA、SuttaCentral (sc/)、84000 (84k/toh)、GRETIL 的既有编号互通。

  • 引 URN，不要引页码。URN 稳定、可机读，且能被第三方独立核对。
  • 只引工具返回的文字。凭记忆复述佛典几乎必然产生异文。
  • 核验之后再输出。verify_quote 一次调用即可。

Skills祖师 skill 目录
