# 研读记忆：同窗配对评测（2026-11-24）

脚本：`backend/eval/memory_pair_eval.py`。读者记忆原文只留在生产机 `/home/admin/eval-mem-data/`，本报告只含汇总。

## 设计（跑之前写定）
- 题目：`eval/test_set.json` 90 题；模型 deepseek-v4-pro，temperature 0。
- 记忆：近 30 天有提问的真实读者按 sha256(user_id+盐) 取 30 人，用线上同一个 `build_study_memory` + `render_memory_block`；第 i 题配第 i % 30 人；每 3 题有 1 题加一条典型自述偏好。
- 两臂：none（无记忆）/ mem（用户轮开头加记忆块）；检索一次两臂共用，同时发出。
- 门槛：①逐字配对「mem 错/none 对」−「mem 对/none 错」≤ 1 且 mem ≥ none − 3pp；②卷号同上；③首字比值中位 ≤ 1.15。最小事件数：逐字两臂可判 ≥ 25。

## 结果（n = 90）

| 臂 | 首字中位 | 总耗时中位 | 输入 token 中位 | 逐字（答案级） | 卷号（引文级） | 引文条数 | 复述背景 |
|---|---|---|---|---|---|---|---|
| none | 27.2 s | 39.2 s | 4,566 | 57/65 = 87.7% | 158/172 = 91.9% | 293 | 0 |
| mem | 32.3 s | 43.3 s | 4,745 | 59/64 = 92.2% | 158/165 = 95.8% | 267 | 1 |

| 门槛 | 结果 | 判 |
|---|---|---|
| 逐字：配对 2 − 5 = −3 ≤ 1（56 题可判，p = 0.45）；92.2% ≥ 87.7% − 3pp | 过 | ✅ |
| 卷号：配对 3 − 7 = −4 ≤ 1（55 题可判，p = 0.34）；95.8% ≥ 91.9% − 3pp | 过 | ✅ |
| 首字比值中位 1.11 ≤ 1.15（90 对） | 过 | ✅ |

**结论：三条门槛全过，默认开启（`settings.study_memory_inject`）。** 忠实度两项方向偏向 mem 但都不显著，读作「没有变差」。

## 注意
- ⚠️ 中途 42 题时首字比值是 1.23（超门槛），我据此提前下过「不能上线」的判断，90 题跑完翻转——**只按预注册的完整样本下结论**。
- 带记忆时模型平均多想约 400–470 字（在判断背景是否相关），首字中位绝对值 +5.1 s。
- 90 题里 1 次复述（「你最近在读《成唯識論》，…」），规则写了「除非读者问起不复述」仍出现。12-24 到期复查看反馈；有人反馈被复述/被盯着 → 关开关。
