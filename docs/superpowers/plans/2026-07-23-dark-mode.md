# Dark Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a warm-dark theme to the fojin frontend, toggled three ways (light / dark / system, default system), that harmonizes with the maroon brand and never hurts reading.

**Architecture:** Three layers — (1) a zustand `themeStore` writes `data-theme` onto `<html>`; (2) `App.tsx`'s single antd `ConfigProvider` switches to `darkAlgorithm` with warmed neutral tokens; (3) `global.css` redefines the existing `--fj-*` semantic tokens under `:root[data-theme="dark"]`. A tiny inline script in `index.html` sets `data-theme` before first paint (no FOUC).

**Tech Stack:** React 18 + TypeScript + Vite, Ant Design 5, zustand (+ `persist` middleware), Vitest.

**Spec:** `docs/superpowers/specs/2026-07-23-dark-mode-design.md`

## Global Constraints

- **Dark accent (chosen):** `#d9693c`. Dark bg `#181410`. (Light stays `#8b2500` / `#f8f5ef`.)
- **Dark `--fj-*` token values (verbatim):** `--fj-bg:#181410` · `--fj-bg-alt:#221d17` · `--fj-ink:#ece4d6` · `--fj-ink-light:#c4b8a4` · `--fj-ink-muted:#a99d89` · `--fj-accent:#d9693c` · `--fj-gold:#c9a86a` · `--fj-border:#39312a` · `--fj-card-bg:#201b15`.
- **Persistence:** localStorage via zustand `persist`, store key **`fojin-theme`** (matches `fojin-auth` naming). Persisted shape is `{"state":{"mode":"..."},"version":0}`.
- **Default mode:** `"system"`.
- **This plan covers P1 (Foundation) only.** P2 (CSS/UI sweep), P3 (data-viz), P4 (walkthrough + public toggle reveal) are separate plans (scoped at the end). The header toggle is functional on the `feat/dark-mode` branch from P1; public exposure happens only when the branch merges after P4.
- **No commit attribution trailers** (repo/user preference): commit messages carry no `Co-authored-by` / `Claude-Session` / "Generated with" lines.
- Lint: ESLint clean; `npx tsc -b --noEmit` passes; `npm test` passes.

// src/stores/themeStore.ts
import { create } from "zustand";
import { persist } from "zustand/middleware";

export type ThemeMode = "light" | "dark" | "system";

/** Pure resolver. MUST stay identical to the inline script in index.html. */
export function resolveTheme(mode: ThemeMode, prefersDark: boolean): "light" | "dark" {
  if (mode === "light" || mode === "dark") return mode;
  return prefersDark ? "dark" : "light";
}

interface ThemeState {
  mode: ThemeMode;
  setMode: (mode: ThemeMode) => void;
}

export const useThemeStore = create<ThemeState>()(
  persist(
    (set) => ({
      mode: "system",
      setMode: (mode) => set({ mode }),
    }),
    { name: "fojin-theme" },
  ),
);
```

// src/theme/antdTheme.ts
import { theme as antdTheme, type ThemeConfig } from "antd";

export function buildAntdTheme(isDark: boolean): ThemeConfig {
  if (!isDark) {
    return {
      algorithm: antdTheme.defaultAlgorithm,
      token: { colorPrimary: "#8b2500", borderRadius: 2 },
    };
  }
  return {
    algorithm: antdTheme.darkAlgorithm,
    token: {
      colorPrimary: "#d9693c",
      borderRadius: 2,
      // warm antd's dark neutrals to match the --fj-* palette (spec: antd dark neutrals note)
      colorBgBase: "#181410",
      colorBgContainer: "#201b15",
      colorBgElevated: "#221d17",
      colorBorder: "#39312a",
      colorText: "#ece4d6",
      colorTextSecondary: "#a99d89",
    },
  };
}

// src/hooks/useTheme.ts
import { useEffect, useState } from "react";
import { useThemeStore, resolveTheme } from "../stores/themeStore";

const MQ = "(prefers-color-scheme: dark)";

export function useEffectiveTheme(): "light" | "dark" {
  const mode = useThemeStore((s) => s.mode);
  const [prefersDark, setPrefersDark] = useState(() => window.matchMedia(MQ).matches);
  useEffect(() => {
    const mql = window.matchMedia(MQ);
    const onChange = (e: MediaQueryListEvent) => setPrefersDark(e.matches);
    mql.addEventListener("change", onChange);
    return () => mql.removeEventListener("change", onChange);
  }, []);
  return resolveTheme(mode, prefersDark);
}

export function useApplyTheme(): "light" | "dark" {
  const effective = useEffectiveTheme();
  useEffect(() => {
    document.documentElement.setAttribute("data-theme", effective);
    const meta = document.querySelector('meta[name="theme-color"]');
    if (meta) meta.setAttribute("content", effective === "dark" ? "#181410" : "#8b2500");
  }, [effective]);
  return effective;
}
```

Insert as the first child of `<head>` (right after `<meta charset>`), so `data-theme` is set before any paint:

```html
<script>
  (function () {
    try {
      var raw = localStorage.getItem("fojin-theme");
      var mode = raw ? (JSON.parse(raw).state || {}).mode : "system";
      if (mode !== "light" && mode !== "dark" && mode !== "system") mode = "system";
      var prefersDark = window.matchMedia("(prefers-color-scheme: dark)").matches;
      var effective = mode === "system" ? (prefersDark ? "dark" : "light") : mode;
      document.documentElement.setAttribute("data-theme", effective);
    } catch (e) {}
  })();
</script>
```

### P2 — CSS / inline-UI hardcoded-color sweep
**Recipe (per file):** for each bare hex / `rgba()` in the 19 `src/styles/*.css` files and inline-styled UI components (`EntityCard.tsx` etc.):
1. Map the color to the nearest existing `--fj-*` token; replace the literal with `var(--fj-token)`.
2. If no token fits (a one-off shade), either add a scoped dark override under `[data-theme="dark"] .selector { … }`, or introduce a new `--fj-*` token in *both* `:root` blocks.
3. After each file, toggle dark and eyeball that page; commit per file (`fix(theme): darken <area>`).
**Order (highest hardcoded-color count first):** `reader.css` (71) → `kg.css` (66) → `sources.css` (50) → `collections.css` (44) → `activity-feed.css` (44) → `global.css` remainder → `master-gallery.css` → `home.css` → `person.css` → the rest.
**Explicitly excluded:** `ShareCard.tsx`, `dynasty_years.ts` (stay fixed — spec).

### P3 — Data-visualization dark adaptation
`ForceGraph.tsx`, `KGTimeline.tsx`, `LanguageDonut.tsx`, `CategoryTreemap.tsx`, `ReaderParallelPanel.tsx`: give each a dark background / axis / label set driven by the effective theme (read `useEffectiveTheme()`), and re-check categorical palette separation + contrast on dark. Categorical *data* hues are retained where they still read; only chrome (bg/grid/labels/tooltips) flips.

### P4 — Full walkthrough + public reveal
