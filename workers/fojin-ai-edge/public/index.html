教学模式

不止一对一

四种教学模式和一个生成器，装进终端里的 AI 工具后可用（网页版目前只有单位祖师）。

/compare-masters

同一个问题，几位祖师并列回答，自动配对汉、藏、南传视角。

/master-debate

就有争议的议题多轮对辩，看清各宗立场的分歧所在。

/master-curriculum

按传统给出由浅入深的学修路径。

/master-help

说出你的状况，推荐该问哪位祖师。

/create-master

按同一套来源与边界规范，生成自定义的祖师技能。

为什么可信

每一句，都能回到原典

祖师技能由佛津驱动：回答之前先检索原典，回答之后可以逐条核对。

有来源

只依声明的典籍

每位祖师声明自己的来源（CBETA、BDRC、Toh、SuttaCentral、PTS），教义断言必须附原典出处。

实时检索

佛津原典库

回答时实时检索佛津的原典与语义索引，附上可点开的原文链接，而不是凭模型记忆复述。

可评测

保真度评测

仓库内置保真度评测与离线引文审计，每次发版都逐条检查引文能否解析到声明来源。

安装

装进你的 AI 工具

只是想体验，直接在网页里用，无需安装、无需注册。

# 一次装全部 21 个技能
npx master-skill install --all
# 不知道该问谁？让它推荐
npx master-skill recommend "念佛怎么念才算老实"

装好后在对话里直接输入 /master-huineng、/compare-masters 等。

codex plugin marketplace add xr843/Master-skill && codex plugin add master-skill@master-skill
# skills.sh：可装进 Claude Code、Codex、Cursor、Gemini 等。必须带 --full-depth
npx skills add xr843/Master-skill --full-depth

各工具的详细步骤见 安装文档。

边界

我们守的几条线

本项目本着对佛教传统的尊重而建立，不做教义评判，不代表任何宗派权威。详见 ETHICS.md。

AI 合成内容。所有回答都不代表祖师亲口开示或亲笔著作。
不传密法步骤。续部修法、灌顶仪轨等只介绍历史与原理。
不作证果判定。修证印证须由具格善知识当面鉴定。
仅供学习参考。正式修行指导，请亲近善知识。

若你正有轻生、自伤的念头，请先联系身边可信的人或心理危机热线（中国大陆 12356；其他地区见 findahelpline.com）。AI 祖师不能代替专业帮助。
