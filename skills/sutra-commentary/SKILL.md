# 经注对读 — 历代注家怎么讲这一句

用 fojin 的经注对齐数据，把「同一句经，历代各家怎么讲、分歧在哪」做成一份
**每一条都能点回原书**的对照。

> 这不是让你凭记忆谈注疏。凡是本 skill 产出的注文，都必须来自工具返回的原文。

## 前置：确认工具在

需要 fojin MCP（`commentaries` / `verify_quote` / `read_passage`）。没有就先：

```bash
claude mcp add --transport http fojin https://mcp.fojin.ai/mcp
```

## 工作流

### 第一步 — 先确认这句经是真的

如果经文是用户凭记忆写的、或来自二手引用，**先 `verify_quote`**。

跳过这一步的后果不是"少一道保险"，而是**你可能在为一句根本不存在的经文编造注解**——
而伪托佛经的句子恰恰是最常被拿来问的（「一花一世界」「前世五百次回眸」都不在藏经里）。

- `verbatim: false` → 停下来告诉用户这句话不在藏经中，给出 `closest` 作为线索。不要继续找注。
- `verbatim: true` 但 `cite_matched: false` → 话是真的、出处是错的。先纠正出处，再往下走。

### 第二步 — 取注

调 `commentaries(quote)`。

**默认 `limit` 是 8，而一段常有 50 家。** 要做对比就把 limit 提到 20–30；
只要 `truncated: true`，你的输出里**必须**写明「本段共 N 家，此处呈现 M 家」。

`matched: false` 时看 `available_sutras`：

> ⚠️ **「这部经还没有数据」不等于「历代无人注过这句」。**
> 说成后者是伪造学术结论。正确说法是：「fojin 目前只覆盖《金刚经》，
> 这一句所属的经尚未收录，因此无法回答，而不是无人注过。」

### 第三步 — 读懂三个最容易误读的字段

| 字段 | 它的意思 | 误读会造成什么 |
|---|---|---|
| `tier` A/B/C | **这部书的对齐质检档次**（程序把注文对到经文上的准确率） | 误当成"这部注疏水平低"。憨山、吉藏的书也可能是 C 档——那说的是对齐难度，不是他的学问 |
| `same_as` | 同一部书收在另一部藏经里的**另一版本** | 把玄宗御注的两个版本当成两家独立意见，**凭空制造共识** |
| `truncated` / `total` | 本段实有 N 家，你只拿到 M 家 | 把样本当全集，得出"只有三家注过"这种错误结论 |

`note` 是**截断过的**（截到该注疏下一处牒文，最多四行）。要引长段，循 `anchor`
回原书，不要把截断处当作注家话说完了。

### 第四步 — 组织成对读

不要平铺直叙地罗列。按这个顺序：

1. **经文本身** —— 用工具返回的 `passage`，标出 `base_urn`
2. **各家分组** —— 能判定宗派/时代的按宗派或时代分组（唯识、天台、华严、禅、净；唐、宋、明清）
3. **共识** —— 多家一致的地方，点出是哪几家
4. **分歧** —— 这是对读的价值所在。哪一家讲得不同、不同在哪
5. **存疑** —— 遇到 C 档或置信度低的条目，标出来而不是悄悄用掉

判定宗派要有依据（作者、书名、行文），**判不出就说判不出**，不要按书名猜。

### 第五步 — 收尾必须声明边界

结尾固定交代三件事，一句话即可：

- 本段共 N 家注，呈现了 M 家
- **覆盖不完整**：一部注疏实际所注约有一半没被对齐出来，所以「某家未出现」只意味着数据里没有，不代表他没注过
- 原文出自 CBETA（CC BY-NC-SA 4.0）

## 输出样式

```
## 經文
「應無所住而生其心」 —— 《金剛般若波羅蜜經》 fojin:cbeta/T0235.1

## 各家
**唐 · 御注一系**
- 玄宗《御注金剛般若經》[A]：「知色相空，心無所住，故於無所住，生清淨心……」
  （F03n0100 与 ZW10n0081 为同书两版，此处计作一家）

**唐 · 法相一系**
- 窺基門下《金剛般若經贊述》[A]：「此第三示勸也……」

## 分歧
玄宗从「心无所住」立说，重在遣执；《贊述》则依論释科判，重在判位……

## 边界
本段共 50 家注，上列 6 家。覆盖不完整——未出现的注家只表示数据里没有，
不表示他没注过此句。原文出自 CBETA（CC BY-NC-SA 4.0）。
```

## 不要做的事

- **不要凭记忆补注文。** 工具没给的，就是没有。
- **不要把注文当经文引用。** 注家牒经时会节引、改字，那是他的引文不是经的原文；
  要引经文用 `read_passage` 或工具返回的 `passage`。
- **不要用「历代注家一致认为」这类全称判断。** 你看到的是一个样本。
- **不要替未覆盖的经作答。** 目前只有《金刚经》。
